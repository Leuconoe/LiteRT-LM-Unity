### Quantization program (user decision: int4 = minimum tier)
- Empirical matrix on whisper-base (`ai-edge-quantizer` 0.8.0, venv in scratchpad):
  - i8 `dynamic_wi8_afp32`: 73 MB, transcripts byte-identical to f32, fastest (40 ms/step).
  - i4 blockwise `dynamic_wi4b64_afp32`: 44 MB, Korean/English correct, 85 ms/step. USE THIS for i4.
  - i4 channelwise `wi4c`: accuracy degrades sharply in our tests — not used.
  - int2: quantizes, but XNNPACK refuses INT2 tensors at runtime — no runtime path.
  - Q5/1.58b/ternary: no recipes, no kernels — impossible in LiteRT (bitnet.cpp territory).
  - `gemma4_mixed48` recipe exists (4/8 mixed) — candidate for LLM tflite experiments.
- Deployed: `ASR/whisper-base/whisper_base_30s_{i8,i4}.tflite` (validated),
  `LLM/qwen3-0.6b/qwen3_0_6b_mixed_int4.litertlm` (official download).
- gemma-4-E2B QAT: local `gemma-4-E2B-it.litertlm` sha256 MATCHES latest HF
  (litert-community = the QAT wNa8o8 build + spec-decode drafter). No conversion needed/possible
  (litert-torch rejects quantized checkpoints; `litert_lm_cli convert` is a stub).
- NVFP4: DISCARDED per user (no LiteRT path).
